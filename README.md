K210 Codex Display Hub 包含 macOS 上位机、网页控制台和 K210 板端程序。上位机从本机 Codex 日志或 Codex 服务获取额度，通过 Type-C 串口更新设备画面；没有设备时也能使用网页预览和演示模式。

<a id="features"></a>

## ✨ 功能特性

- **Codex 状态**：显示 5 小时与 7 天额度、当前任务状态和模型。任务状态根据本机日志推断，启动时恢复长会话的任务开始和模型记录，排除内部自动审核，并按任务 ID 确认完成。
- **重置预告**：右下角模型位显示公开重置或发卡消息及倒计时；没有有效消息时恢复模型名，点击模型名或消息徽标都可查看重置信息。网页提供原帖链接和消息开关。
- **两种桌面**：在 Codex 信息页与数字时钟页之间切换；同时显示时间和天气。
- **网页预览**：在浏览器查看并点击 K210 画面，设置串口、数据来源、时区和天气。
- **触屏设置**：在 K210 上切换桌面、翻转屏幕、调节亮度并查看设备信息。
- **同步与更新**：支持手动同步、设备端点击 7D 额度圈同步，以及通过串口更新 `main.py`。
- **菜单栏应用**：打开控制台、查看连接状态、同步、重连和设置开机自启。

## 📦 安装与运行

上位机需要 macOS 和 Python 3。使用真实数据需要本机 Codex 日志或已登录的 Codex 命令行程序；演示模式不需要 K210 或 Codex 账号。在项目根目录运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py --source demo --serial '' --open
```

控制台默认地址为 <http://127.0.0.1:2100>；端口可在配置中修改。读取真实数据时运行 `.venv/bin/python run.py`。从源码启动 macOS 菜单栏应用可运行 `.venv/bin/python tray_app.py`。

点击应用图标会启动后台并自动打开控制台；软件已运行时，再次点击会打开现有后台的控制台，不重复启动后台。开机自动启动保持后台运行，手动点击图标时再打开网页。

<a id="device"></a>

## 🔌 连接 K210

1. 用 CanMV IDE 将 `K210/main.py` 和 `K210/program_update.py` 保存到开发板同一目录：使用 MicroSD 时分别为 `/sd/main.py`、`/sd/program_update.py`，否则分别为 `/flash/main.py`、`/flash/program_update.py`，然后重启设备。主程序将在线更新代码延后加载，以给屏幕画布留出启动内存。
2. 断开 CanMV IDE 对串口的占用。在网页中选择“USB 连接（115200）”，扫描并选择 K210 的 Type-C 串口，然后点击“连接”。
3. 点击“连接”，等待页面显示“已收到设备确认”。

### 外接蓝牙串口（HC-05 等）

P7 是 K210 的 IO7/TX，接 HC-05 的 RX；P6 是 IO6/RX，接 HC-05 的 TX；两端 GND 必须相连。HC-05 的 VCC 应按所购模块底板的标注供电，TX/RX 使用 3.3V 逻辑电平。

## ⚙️ 配置与开发

源码运行时，设置保存在项目根目录的 `config.local.json`；打包应用保存在 `~/Library/Application Support/K210 Codex Display Hub/config.json`。配置模板见 `config.example.json`。默认数据来源为本机日志，天气默认自动定位；网页中可改为手动城市。`config.local.json` 已被 Git 忽略。

使用 Codex 服务时，上位机会从 PATH、常见 CLI 安装目录及 `/Applications`、`~/Applications` 中的 ChatGPT/Codex 应用包查找 `codex`。菜单栏启动不继承终端 PATH；若使用其他安装位置，可将配置中的 `codex_bin` 设为可执行文件的绝对路径，然后重启上位机。天气与额度独立查询；天气错误会区分自动定位、城市查询和天气查询，并提示超时、DNS 或 HTTPS 等原因。

测试与 macOS 打包：

```bash
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python -B -m unittest discover -s tests -v
.venv/bin/python build.py
```

打包结果位于 `dist/K210 Codex Display Hub.app`。修改板端字体后，可用 `.venv/bin/python tools/generate_fonts.py --check` 核对两份 K210 程序的字形。

## 🔐 数据说明

上位机可读取 `~/.codex` 中的会话日志，或调用本机 `codex app-server` 查询额度。天气使用 Open-Meteo；默认自动定位会请求 `ipwho.is`，由该服务看到公网 IP。网页服务仅监听 `127.0.0.1`，接口没有登录认证，不要将其端口公开。在线更新会改写设备程序，请先确认所选文件。

网页预览按需生成：前台每秒刷新，隐藏时每 10 秒仅获取状态，关闭网页后不再绘制预览，闲置 1 分钟释放帧缓存，再次打开时重建。后台继续设备通信、额度查询和天气更新；默认每 5 分钟查询服务额度、每 20 分钟更新天气。

更新 K210 主程序时，小屏幕将当前画面模糊并压暗，在前方显示“正在执行更新···”、“请勿断电！！！”和本地进度条；控制台保留原有更新状态，不遮挡网页。上传前等待在途请求结束，上传期间设备通道独占给升级数据和校验回执，暂停额度、天气、重置消息查询和预览绘制；网页只查询轻量进度接口。设备重启确认或更新失败后自动恢复，准备阶段的保活及重启后的必要握手仍会执行。屏幕进度直接按已接收字节计算，不增加进度通讯报文；模糊只在开始时执行一次，旧固件缺少滤镜时使用纯色背景，保证更新继续。

重置消息默认开启，由上位机每 15 分钟查询 [AIhot 近期消息接口](https://aihot.news/api/v1/codex-resets/recent)，不使用 Codex 登录凭据，也不改变账户额度。手动检查至少间隔 1 分钟，避免重复读取相同缓存；完整历史接口存在每客户端 10 分钟一次的限制，本项目不再轮询完整历史。预告按具体时刻、时间区间或截止时间计算倒计时；只有日期时显示日期。公开确认来自消息源，不代表个人账户已经到账。请求失败保留上次成功消息并提示陈旧，限流时遵守服务端的重试时间并显示最早可重试时间；过期消息自动隐藏。网页“重置消息”区域可关闭该功能，演示模式只显示明确标注的模拟预告。

使用实体屏幕的新徽标和详情页时，需要通过网页更新 `K210/main.py`。新增字形随主程序内嵌，本次不需要替换已有的 `font.bin`。

右下角模型名和重置提示使用原生 15 像素字形，模型文字采用高对比配色；超长模型名在固定区域内来回滚动，两端稍作停留，较短名称仍居中。底栏各部分独立排布，避免状态文字遮挡。

重置信息入口覆盖右下角 `x=216–315、y=156–239` 的区域，包含 7D 圆环右下部分和模型名／消息徽标。与圆环同步区重叠的位置优先打开重置信息，圆环上半部分仍可触发同步；网页预览和实体屏幕使用相同范围。

确认发卡或确认重置后，进入详情会将该条确认消息标记为已读，返回首页后右下角恢复模型名；详情和后台消息仍保留到原定过期时间。已读记录随现有设置保存，刷新、重连或重启后同一条消息不再提示，新确认消息会再次提示；预告和倒计时不受已读影响。模拟预览的已读状态仅作用于模拟内容。

重置信息详情使用原生 20 像素标题、18 像素时间和正文、15 像素状态及来源底栏；正文采用高对比白色并保持居中，新增字形内嵌在主程序中，兼容设备原有 `font.bin`。

打开网页“重置消息”标题栏的“预览”开关，主页和详情页会持续模拟重置或发卡消息。展开“模拟内容设置”可选择暂无消息、预告或已确认，并设置消息类型、时间精度和具体时间；开启时修改自动生效，关闭后隐藏整个模拟设置区域。时间按控制台所选时区输入；模拟内容只改变左侧画面，不覆盖公开消息、不写入配置，也不发送到 K210。主页右下角显示对应消息徽标，点击进入详情；返回主页、修改内容或刷新网页都会保留模拟状态。关闭“预览”开关恢复实时画面，重启后台也会关闭预览。
